# HMi - new home banner (proposal)

A working prototype of the new hmi-ad.com home banner, rebuilt from the client's
mockup as real HTML text and real buttons instead of one flat JPEG.

- 3 slides, fade transition, auto-rotates every 6 seconds
- pauses on hover, on keyboard focus, and when the browser tab is hidden
- arrows, dots, keyboard left/right, swipe on touch
- responsive: two columns on desktop, stacked on mobile, no horizontal scroll
- respects prefers-reduced-motion

Copy on slides 2 and 3 is placeholder, for the client to approve or replace.
Images are the client's own, used here only for this proposal.
